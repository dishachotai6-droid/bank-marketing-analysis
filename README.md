# Bank Marketing Analysis

## Project Overview
This project analyzes customer data from a bank marketing campaign to identify factors affecting term deposit subscriptions.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Analysis Performed
- Customer Demographics Analysis
- Campaign Effectiveness Analysis
- Correlation Heatmap
- Logistic Regression Modeling
- Feature Importance Analysis

## Key Findings
- Longer call durations are associated with higher subscription rates.
- Contact methods influence customer responses.
- Campaign frequency affects outcomes.
- Logistic Regression can predict customer subscription behavior.
